What is K-Means?

K-Means is an unsupervised algorithm that splits unlabeled data into k clusters. Each cluster is summarized by a centroid, the mean position of its points.

The loop

  1. Initialize: pick k starting centroids.
  2. Assign: each point joins its nearest centroid.
  3. Update: each centroid moves to the mean of its points.
  4. Repeat until no point changes cluster.

The math

J = sum over clusters j, sum over points x in cluster j of ||x - mu_j||^2

Both steps can only lower J or keep it the same, so the algorithm always stops, at a local minimum.

Experiments to try

  • Set k to a different value than the real number of groups and see what happens to the inertia.
  • Press Restart several times with random starts: results can differ. Then try k-means++.
  • Choose Two rings. K-Means cannot separate them, because it assumes round clusters.
  • Use 300 points and k = 8 to see how fast it converges on larger data.
